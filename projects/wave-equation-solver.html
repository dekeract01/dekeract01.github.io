Wave Equation Benchmarks

This continuing project uses a one-dimensional linear advection solver to compare numerical implementations across languages, CPU parallelism, distributed-memory computing, and GPUs. The equation is intentionally compact: it makes the full calculation understandable while still exercising grids, boundary conditions, time integration, verification, file output, builds, and performance measurement.

For a periodic sine wave, the analytical solution simply translates without changing shape. Every implementation can therefore be checked against that exact result rather than judged only by its timing.

dphi/dt = -c0 dphi/dx
phi(x, 0) = sin(2pi x)
phi_exact(x, t) = sin(2pi(x - c0 t))

Methods and Implementations

The solver uses fourth-order central differences in space with third-order Runge-Kutta time integration. The benchmark runs on a periodic domain with 2,000,000 grid points, a wave speed of 0.5, a time step of 10-7, and 1,000 iterations.

The repository includes serial C++, Fortran, Julia, Python, Python with Numba, and Rust versions, alongside OpenMP C++, MPI C++, MPI Fortran, OpenCL C++, and CUDA C++ implementations. The CPU and CUDA C++ versions use double precision; the OpenCL version currently uses single precision.

Run It

git clone https://github.com/dekeract01/wavebench.git

The repository contains the current code, scripts, benchmark details, and results. The charts describe a particular machine and configuration, rather than universal language rankings.
