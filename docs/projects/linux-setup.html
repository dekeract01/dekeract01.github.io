Linux Setup

20 February 2022
Last updated

Repository
linux-setup

Every time I install Linux on a new machine, there's the same afternoon of setting everything up again. Installing the same software, removing the same apps I never use, setting up git, ssh keys, the firewall, VS Code. So I wrote a script to do it all for me.

My distro of choice has been Fedora ever since my first year of uni. I only found out later on how big Red Hat Enterprise Linux actually is, and that Fedora is basically where RHEL starts out. Loads of servers and HPC clusters run on the RHEL family, so it turns out I'd been getting used to it without really meaning to.

The idea came from my friend Matt, who wrote his own setup scripts for openSUSE. I took inspiration from his and wrote one for Fedora first. Then I ended up looking after my supervisor's server, which ran the original version of OpenSBLI, so I made a version for that machine too, and that's the one that went up on GitHub back in February 2022. I made one for macOS at the same time.

Coming back to it now, I've cleaned them all up properly and put all three in the same repo. Each one is broken into steps, and you switch them on or off at the top of the script, or just run the ones you want.

The bit I like most is how little you actually have to do. On a fresh install you don't even need git. Just grab the repo with curl (or wget), have a quick look at the settings at the top of the script, and run it:

curl -fsSL https://github.com/dekeract01/linux-setup/archive/refs/heads/main.tar.gz | tar -xz
cd linux-setup-main
./linux/setup/setup_fedora.sh

I've always liked automating things, and this is one of those small ones that saves a surprising amount of time. Install the OS, run one script, go make a cup of tea.
