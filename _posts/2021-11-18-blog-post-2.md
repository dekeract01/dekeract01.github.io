Getting started with AcademicPages has been quite an adventure! Coming from a MinimalPages background, I found the template structure to be significantly different and much more complex than I initially anticipated.

## Initial Setup Challenges

The biggest hurdle was getting the styling and theming right. Unlike MinimalPages, AcademicPages required extensive customization to achieve the visual consistency I was looking for. The contrast skin, in particular, needed a lot of hard coding to get it working properly across all page elements.

Some of the key areas that required manual tweaking:
- **Colour scheme consistency** - ensuring all elements used the same palette
- **Typography settings** - getting fonts to display consistently across different page types
- **Navigation alignment** - making sure the masthead properly aligned with content
- **Sidebar styling** - customising the author profile section

## Configuration Deep Dive

The `_config.yml` file in AcademicPages is much more comprehensive than other Jekyll templates, which is both a blessing and a curse. While it offers incredible flexibility, it also means there are many more moving parts to configure correctly.

I spent considerable time understanding the relationship between the various SCSS files and how they interact with the site's overall styling system.

## Next Steps

---------------------------

**Upcoming Improvements:**
- **Dark mode toggle** - This is my top priority. I want to implement a proper dark/light mode switcher that respects user preferences and maintains consistency across all pages.
- **Enhanced navigation** - Fine-tuning the menu structure and possibly adding breadcrumbs
- **Performance optimisation** - Reviewing and optimising the build process
- **Page bloat reduction** - One thing that's really bothering me is how long some pages take to load. There's definitely too much bloat in the current setup, and I'd like to streamline the CSS and JavaScript to improve loading times. It's not acceptable for an academic website to be sluggish.

Overall, whilst AcademicPages has a steeper learning curve than simpler templates, the flexibility and features it offers make the extra effort worthwhile. The end result is a much more professional and feature-rich academic website.
